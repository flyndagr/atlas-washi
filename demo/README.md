# Atlas showcase

The finished videos in `docs/media/` are 18-second H.264/AAC product showcases composed from actual Atlas screenshots of the original sample notebook. They are not live recordings of typing or dragging. No personal notes appear.

- `atlas-demo.mp4`: 1280×720
- `atlas-demo-square.mp4`: 1080×1080
- `atlas-demo-vertical.mp4`: 1080×1920
- `captions.srt`: matching captions, also burned into each composition
- `*-contact.jpg`: four beats at 390 pixels wide
- `*-share.png`: standalone sharing images with the current repository address

All demo end cards and share images point to `https://github.com/flyndagr/atlas-washi`. The address is defined once as `REPO_URL` in the renderer.

## Reproduce

Use Python 3 and a virtual environment; install `demo/requirements.txt`. From the repository root run `python demo/render.py`. FFmpeg comes from the imageio-ffmpeg wheel. The soundtrack is an original procedural motif generated by the script. See `DECISIONS.md` and `directions.html` for the creative brief.

To refresh the underlying app screenshots, build Atlas, then run:

```sh
./target/release/atlas --vault "$PWD/demo/notebook" --screenshot "$PWD/docs/media/notebook.png" --quit-after-screenshot
./target/release/atlas --vault "$PWD/demo/notebook" --canvas --screenshot "$PWD/docs/media/canvas.png" --quit-after-screenshot
./target/release/atlas --vault "$PWD/demo/notebook" --focus --screenshot "$PWD/docs/media/focus.png" --quit-after-screenshot
```

Pin the three sample notes before capturing canvas. Runtime `.atlas/` files are deliberately ignored by Git. For the shipped composition, card positions are `[40,40]`, `[420,80]`, `[225,285]` in alphabetical note order, with zero pan.

## Verification performed

All three exports decode successfully: 18.00 seconds, 540 frames at 30 fps. Duplicate rendering of a selected frame is byte-identical. Four-beat contact sheets were inspected for composition and caption readability. Measured audio is −15.8 LUFS integrated with a −4.2 dBFS true peak. There is no speech; the captions carry the whole message when muted. Listening/playback review was not performed by a human.

The Japanese 静 seal uses the same `assets/seal.json` geometry, color, glyph, and Shippori Mincho font as the app. Its aspect ratio stays fixed across landscape, square, and portrait exports.
